# CampusCart delivery checklist

## Storefront and discovery

- [x] The website presents CampusCart as a student-focused e-commerce platform for affordable campus food, groceries, stationery, and everyday essentials.
- [x] Students can browse a catalogue with category filters for Food, Groceries, Stationery, and Essentials.
- [x] Product cards show product names, short descriptions, categories, prices, and a clear add-to-cart action.
- [x] Selecting product details opens a focused view with the item's description, price, delivery note, and add-to-cart action.

## Cart and order request

- [x] Students can add products to the cart, see the cart count, change quantities, remove items, and see an updated subtotal.
- [x] The order summary shows selected items, quantities, subtotal, delivery fee, and final total.
- [x] The checkout flow collects a student's name, phone number, campus location, and optional note before submitting an order request.
- [x] A successful order request shows a confirmation state with an order reference and pickup/delivery expectation.
